## 复习顺序

1. 阅读 Lec 6 笔记，完成例题 1–8；重点重做第 63 页 CNF 小测和完整 CYK 表。
2. 阅读 Lec 7 笔记第 1–4 节，完成例题 9–14；每台机器都检查空串、最短接受串、计数错误和顺序错误。
3. 阅读 Lec 7 笔记第 5–8 节，完成例题 15–18；重点解释三元组变量及 DPDA 的两项条件。
4. 用 35–45 分钟独立完成 8 道自测，再核对答案。

如果只有约两小时，可用 30 分钟复习化简与范式、20 分钟练 CYK、35 分钟练 PDA 构造、20 分钟复习 CFG/PDA 互转与确定性，最后 15 分钟检查错题。该时间安排是学习建议，不代表考试题型或分值。

## 来源与约定

课件版本对应仓库提交 [`9e10230`](https://github.com/gingersea/3130/tree/9e10230b632402e8afd5630f13b12424c5f01d65)。笔记中的页码均指 PDF 页码。例题明确标记课件题、改编题与补充题；证明中的补充说明与课件未展开的前提也单独注明。

全文用 $\lambda$ 表示空串，栈串左端为栈顶；PDA 默认终态接受且输入必须全部读完。注意课件第 174 页两种等价栈编码的区别，详见例题 17。第 81 页的计数图若要识别严格的 $a^*b^*$ 形式，需要另加顺序约束。

## 重新生成 PDF

需要 Pandoc、XeLaTeX、`xeCJK` 及 Noto CJK 字体。在仓库根目录执行：

```bash
bash review/build.sh
```

PDF 由 Markdown 生成；修改正文后运行上述命令即可保持两个版本一致。

## 核验范围

编写时逐页提取课件文字，并查看图片形式的小测、CYK 表和关键状态图。使用临时脚本核对文法转换的有界生成语言、完整 CYK 表，以及 PDA 在有限长度输入上的接受结果和确定性条件。有限枚举用于发现算错和边界遗漏，不能代替文中给出的不变式与等价性论证。
